# **App Name**: MC Billing

## Core Features:

- User Authentication and Roles: Secure login system with role-based access control (RBAC) for Creators, Admins, and Managers, leveraging JWT and bcrypt/argon2.
- Bilingual Customer/Product Search: Search customers and products by ID, English name, or Tamil name, enhancing usability in a multilingual environment.
- Real-Time Multi-User Billing: Enable multiple users to add items to the same bill concurrently, with updates visible in real-time to all users.
- Live Bill History Panel: Display a live history panel of all bills/items entered up to the current moment, auto-updated on every new entry for quick review and editing.
- Past Bill Editing and Audit Trail: Allow Admin and Manager roles to open and edit past bills, with all edits logged in an audit trail for accountability.
- Product Lock Mode: Implement a 'Product Lock' mode for fast entry of multiple items of the same product, streamlining billing in high-volume scenarios.
- Thermal Printer Configuration: Dedicated settings page in dashboard to set printer specific properties like paper width, font size, header, visibility properties and provide test print option.

## Style Guidelines:

- Primary color: Deep sea blue (#293A4F) to evoke reliability and trustworthiness.
- Background color: Light grayish-blue (#E5E7EB) offering a clean, unobtrusive backdrop.
- Accent color: Muted teal (#2A9D8F) for interactive elements and important CTAs.
- Body font: 'Inter' (sans-serif) for a modern, neutral, and readable text.
- Headline font: 'Space Grotesk' (sans-serif) for a contemporary and slightly techy headline.
- Use minimalist icons that relate to billing, products, and user roles.
- Design a mobile-first responsive layout that adapts seamlessly to different screen sizes, with clear visual hierarchy.
